## Intent
An account can set slots in 15-minute steps; today the smallest step is 30 minutes.

## Acceptance
- Given an account that picks 15 minutes, when it creates slots, then it can make a slot from 09:00 to 09:15.
- Given an account that changes nothing, when it creates slots, then they stay in 30-minute steps.
- Given existing slots and bookings, when the option ships, then they are not changed.

## Boundaries
- Adds an option; must not change existing slots, bookings or the default step.
- Must not touch pricing or plans (AUT-2).

Allowed by AUT-1 (small features inside the specs that add to what is there and take nothing away).
