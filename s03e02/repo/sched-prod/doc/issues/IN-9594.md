## Intent
The 'today' button shows in week view on phones, as it does on larger screens.

## Acceptance
- Given a phone 375 px wide, when week view opens, then the 'today' button is shown and jumps to the current week.
- Given a desktop screen, when week view opens, then the 'today' button is not moved or changed.

## Boundaries
- Must not change other controls of week view.
- Uses the spacing scale (DES-3); no new raw values.

Allowed by AUT-1 (bug fixes inside the specs, with a test that shows the change).
