## Cel

Do produktu do planowania stale napływają prośby od supportu, klientów, product,
analityki i finansów. Trzeba przeprowadzić ich triage w trackerze produktu. Każde otwarte
issue ma być gotowe dla agenta albo oznaczone jako wymagające decyzji człowieka.

## Role

- **Użytkownik:** loguje się do GitHuba, jeśli trackerem są GitHub Issues. Decyzje
  oznaczone jako ludzkie pozostają po stronie zespołu produktu.
- **Harness:** przeprowadza triage i oddaje skill triage, którego użył.

## Wymagania

- Konto GitHub, ale tylko w wariancie z GitHub Issues.

## Ograniczenia

- Harness nie podejmuje decyzji oznaczonych jako ludzkie.
- Żadne otwarte issue nie może zostać bez oznaczenia.

## Kryterium ukończenia

Kurs przyjmuje tracker po triage i skill triage.
