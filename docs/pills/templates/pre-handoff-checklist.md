# A6 · Checklist before handing over (claim, PR, report)

- [ ] The recipient's contract is read and the answer shape matches ([P06](../02-contracts-and-done/p06-contract-first.md)).
- [ ] Sources fetched again and diffed against the previous read ([P04](../01-context/p04-a-download-is-a-dated-copy.md)).
- [ ] The "done when" check passes and I have its output ([P07](../02-contracts-and-done/p07-done-is-a-check.md)).
- [ ] The result checked from outside, as the recipient will see it ([P10](../02-contracts-and-done/p10-check-from-outside.md)).
- [ ] Steps waiting on the other side are still open ([P09](../02-contracts-and-done/p09-sent-is-not-confirmed.md)).
- [ ] No secret in a commit, a log or an answer ([P32](../06-security/p32-secrets-never-in-chat.md)).
- [ ] Handover file or debrief updated ([P12](../03-memory/p12-chat-is-not-memory.md)).
