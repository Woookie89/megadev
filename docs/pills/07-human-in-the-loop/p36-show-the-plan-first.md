# P36 · Show the plan before you publish

> Chapter [7. Human in the loop](README.md) · episodes: S01E04

> **Lessons:**
> - S01E01 · Mechanics Behind Generative AI → chapter "Platforms and Harnesses" — [original (EN)](../../../s01e01/s01e01-mechanics-behind-generative-ai.md#platforms-and-harnesses) · [Polish: „Platformy i harnessy”](../../pl/s01e01-mechanics-behind-generative-ai.md#platformy-i-harnessy)

**Principle.** For work with public effects, the agent first shows the plan or the split
and publishes nothing until it is approved.

**Case.** S01E04, the `plan-to-issues` skill: stop, show the split table, publish nothing.
MEGA Assessment (strength): phases of recon → recommendation → build, with implementation
only after the first phase has been read.
