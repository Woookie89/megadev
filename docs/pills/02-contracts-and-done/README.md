# 2. Contracts and "done"

On its own, an agent stops when it stops calling tools. That is not the same as "the task
is done". This chapter is about agreeing up front what the other side expects, and checking
that it got it.

| [P07](p07-done-is-a-check.md) | "Done" is set by a check, not by a feeling that the work is over | S02E01, MEGA Assessment |
| [P08](p08-test-must-fail-first.md) | A test that was never red proves nothing | S01E05 |
| [P09](p09-sent-is-not-confirmed.md) | A step that waits on the other side closes when they confirm | S01E04 |
