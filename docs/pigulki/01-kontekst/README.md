# 1. Kontekst: model wie tylko to, co do niego trafi

Model nie ma dostępu do świata. Ma tylko okno kontekstu, czyli tekst (i obrazy), który
harness do niego włożył. Wszystko, czego tam nie ma, dla modelu nie istnieje. Wszystko, co
tam jest, ale jest nieaktualne albo przekłamane, model weźmie za prawdę.
