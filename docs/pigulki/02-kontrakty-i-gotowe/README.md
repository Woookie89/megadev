Agent sam z siebie kończy, gdy przestaje wołać narzędzia. To nie to samo co „zadanie
zrobione”. Ten rozdział jest o tym, jak z góry ustalić, czego oczekuje druga strona, i jak
sprawdzić, że to dostała.
