### nothing ships unmarked

Requests for a scheduling product keep arriving from support, clients, product, analytics and finance. Triage them into its issue tracker with your harness, so every open issue is either ready for an agent or marked for a person.

**You do**\
Nothing, unless your harness keeps the tracker in GitHub Issues: then you sign it in to GitHub. Issues marked for a person are for the product's people to decide, not you.

**Your harness does**\
It triages the product's requests into its issue tracker, so every open issue is either ready for an agent or marked for a person.

**You need**\
A GitHub account, only if the tracker is GitHub Issues.

**Done when**\
