A metric that counts only one logging path cannot prove a win. Before you call a release a win (or expand it), check whether the action moved off the measured path: another tab, another tool, a manual step, an event that replaces the one you count. Watch a replay or read a raw event of each arm. If the win exists only on the counted path, the verb is investigate or revert, not expand.

Why: S03E05. Suggestions v2 cut board restarts by 12%, but after Accept operators restarted the worker in sched-admin, which the board never logged. Auto-close cut open incidents by 21.7%, but the stalled queues were only closed on the board and handled in sched-desk.

How to apply: when you cite the evidence, name the file, the second and the region of the replay, and use full-resolution frames for ids and numbers. For the whole method use the skill `decide`.
